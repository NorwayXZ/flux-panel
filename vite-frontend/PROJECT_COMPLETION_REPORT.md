### 架构设计

```
┌─────────────────────────────────────────┐
│           React Query Layer             │
│  (数据获取、缓存、状态管理)              │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│         Custom Hooks Layer              │
│  (业务逻辑、状态管理、工具函数)          │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│          UI Components Layer            │
│  (可复用组件、布局组件)                  │
└─────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────┐
│            Pages Layer                  │
│  (页面组件、路由配置)                    │
└─────────────────────────────────────────┘
```

## 💡 最佳实践建议

### 开发建议
1. **优先使用新组件** - 替换旧组件，保持一致性
2. **遵循 TypeScript** - 严格的类型定义
3. **编写清晰注释** - 帮助团队理解
4. **测试覆盖** - 确保代码质量
5. **性能监控** - 持续优化性能

### 代码规范
- 使用 ESLint 和 Prettier
- 遵循 React Hooks 规则
- 组件命名采用 PascalCase
- Hooks 命名以 use 开头
- 文件命名采用 kebab-case

### Git 提交规范
```
feat: 添加批量操作功能
fix: 修复虚拟滚动高度计算问题
docs: 更新快速入门文档
style: 优化卡片组件样式
refactor: 重构数据导出逻辑
perf: 优化列表渲染性能
test: 添加批量选择单元测试
```
