# 2.52.0 实际发布范围

本版本在提交 `bbd7dea` 基础上完成可构建、可操作的前端集成。既有授权入口模块继续使用原有后端接口，新路由文件 `src/pages/AuthorizedEntriesPage.tsx` 复用该模块。

- 授权页面：搜索、缓存、15 秒刷新、骨架屏、加载失败重试、批量启用/暂停/撤销、按当前结果选择及 CSV/Excel/JSON 导出。批量操作保留失败项，撤销需要确认；普通用户没有管理员按钮，也不请求管理员资源。
- 大列表：超过 60 项授权时启用响应式虚拟网格。组件支持动态行高、容器宽度变化和稳定项目键；本地浏览器验证使用 150 项测试授权。
- 共享基础：React Query Provider、API hooks、断点 hooks、卡片/徽章/骨架组件、设计令牌和导出入口。Excel 依赖按需加载，开发工具只在开发环境渲染。
- 发布版本：面板、Agent 和 Connector 均使用 `2.52.0`。既有 `v2.52.0` 标签属于最初的未完成构建快照，正式镜像和安装附件使用经过发布流水线验证的 `2.52.0` 标签。

`npm test` 验证账号缓存隔离、请求去重、普通用户资源访问边界、异步列表选择/重置、断点及 CSV 转义。发布流水线另执行后端全量测试、运行检查、Agent 测试、各平台构建和镜像内容校验。

早期规划和汇总文档中的“提升 50%/94%”“减少 80%”等数字没有基准测量支持。本版本不保证这些数字，也没有宣称所有业务页面已经完成 React Query 或虚拟滚动迁移。完整节点管理页面继续保留原有操作和遥测流程。
